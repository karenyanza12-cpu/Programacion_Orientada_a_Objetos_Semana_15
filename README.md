# AMALIA RESTAURANT - Semana 15

## Programación Orientada a Objetos

Proyecto correspondiente a la Semana 15 de la asignatura Programación Orientada a Objetos.

El proyecto continúa el sistema desarrollado en las semanas anteriores para AMALIA RESTAURANT.

## Objetivo

Incorporar los fundamentos básicos del manejo de eventos mediante una operación de venta.

La aplicación permite relacionar usuarios con productos y registrar ventas desde una interfaz gráfica desarrollada con Tkinter.
